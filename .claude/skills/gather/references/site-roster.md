# Site roster

Public market-research publishers worth studying, and the one thing each is
worth studying *for*. Look at the surface named in "Study for" first — that is
where that site is ahead of us.

## Primary — healthcare / life-sciences overlap with our corpus

| Site | Study for |
|---|---|
| grandviewresearch.com | Report-page section order and depth; segment tables; TOC structure |
| marketsandmarkets.com | Taxonomy and category navigation across thousands of reports |
| mordorintelligence.com | Report page information density and chart-per-page count |
| fortunebusinessinsights.com | Listing filters, pagination, and card fields |
| precedenceresearch.com | Free-prose depth before the gate; statistics pages |
| towardshealthcare.com | Healthcare-only framing; how they present a narrow corpus |
| researchandmarkets.com | Catalogue scale UX: search, sort, licence/price tiers |
| globaldata.com | Analyst attribution and credential presentation |

## What not to bring back

Recorded and rejected on sight, because we are a publication and not lead-gen:

1. Email walls in front of a report's own prose.
2. Exit-intent and scroll-depth popups.
3. Live-chat and "speak to an analyst now" widgets.
4. Countdown timers, "only N licences left", discount urgency.
5. Fabricated client-logo walls and unattributed testimonials.
6. Any competitor's market figures, report titles, taxonomy strings or copy.

If a run produces one of these as a finding, write it in the site note under
**Rejected** with one line of why, so the next run does not re-file it.
